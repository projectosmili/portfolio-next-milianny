# Journal

Este espacio funciona como diario técnico y profesional.

## Qué registrar
- Qué hice
- Qué aprendí
- Problemas encontrados
- Cómo los resolví
- Bloqueos
- Pendientes
- Ideas
- Decisiones importantes
- Notas de reuniones
- Retroalimentación recibida
- Lecciones aprendidas

## Formato recomendado
Usar una entrada por día con fecha y secciones claras.
