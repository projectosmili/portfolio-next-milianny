# Workspace Context

Esta carpeta centraliza tres espacios persistentes para organizar el trabajo del portfolio y del desarrollo personal.

## Pestañas de contexto
- About Me: perfil profesional, carrera, CV, LinkedIn, roadmap, habilidades y PDI.
- Projects: proyectos de software con contexto independiente por proyecto.
- Journal: diario técnico y profesional con entradas por fecha.

## Reglas
- No mezclar información entre pestañas.
- Si una nota pertenece a tu carrera, usar About Me.
- Si pertenece a un proyecto, usar Projects.
- Si pertenece al trabajo diario o aprendizaje, usar Journal.
- Mantener esta estructura limpia y escalable.
